It keeps ABI major 1 and its append-only compatibility model, while providing applications with a much broader set of resident services:\r\n\r\n- direct RX audio capture from PA4;\r\n- a precise 48 MHz cycle clock for demodulators and timing-sensitive applications;\r\n- resident integer formatters and frequency rendering;\r\n- application-to-application hand-off with a bounded message payload;\r\n- a quiet `tx_prepare` path for applications that control RF keying themselves;\r\n- USB-C serial-port services, initially used by KISS TNC;\r\n- page-level and byte-paced LCD output;\r\n- K5Viewer updates separated from LCD writes, so time-critical receivers are not blocked by screen mirroring;\r\n- deferred VFO changes applied safely when an application exits;\r\n- more consistent API layout and capability reporting across firmware editions.\r\n\r\nExisting applications that only require an earlier API level remain compatible with the append-only ABI. Applications that require API level 3 must be used with firmware v6.3.0 or later.\r\n\r\n# 🆕 Ten new overlay applications\r\n\r\nThe Labs collection grows from 30 to 40 applications. New in this release:\r\n\r\n- **AIS RX** — receives 9600-bit/s AIS traffic on AIS 1 or AIS 2 and decodes Class A, Class B, static, voyage and European Inland AIS reports. It displays vessel identity, position, speed, heading, destination and inland-navigation data. Real AIS reception has been validated.\r\n- **ATIS DSC RX** — receives VHF Digital Selective Calling on marine channel 70 and displays distress, urgency, safety, routine and test calls, including MMSI, destination, distress nature, time and position. Bench-tested on radio; live channel-70 traffic remains to be validated.\r\n- **KISS TNC** — turns the radio into a Bell 202 AFSK 1200 AX.25 TNC connected through USB-C. APRSdroid or another KISS client handles the map, messaging and beacon logic while the radio performs RF reception and transmission.\r\n- **Sonde M10** — decodes Meteomodem M10 radiosondes and displays serial number, position, altitude, temperature, humidity, vertical speed, horizontal speed and heading. Live radiosonde reception has been validated.\r\n- **Sonde RS41** — decodes classic and newer multi-GNSS Vaisala RS41 frames, displaying position, altitude, vertical and horizontal speed, heading and battery voltage. Classic RS41 reception has been validated in the field; multi-GNSS support is currently validated with synthetic frames.\r\n- **CW USB** — a dedicated USB-C straight-key and paddle application derived from CW Keyer, with deliberate transmitter arming and selectable automatic, iambic A and iambic B modes. Thanks [@jdenoy](https://github.com/jdenoy) and [@lemiller-dev](https://github.com/lemiller-dev).\r\n- **AF Scope** — an oscilloscope and audio-frequency tuner for the demodulated receiver output, with triggering, gain, persistence, peak detection, frequency measurement and known-tone comparison.\r\n- **AF Spectro** — an audio spectrum and sonogram analyser with peak hold, two-tone detection and twist measurement for signals such as Bell 202 AFSK.\r\n- **Resistor** — a 3-, 4-, 5- and 6-band resistor colour-code calculator with direct colour entry, tolerance and temperature-coefficient support.\r\n- **Hell Maze** — a first-person fixed-point raycasting game with textured walls, enemies, sound effects and an on-screen help page.\r\n\r\nAF Scope and AF Spectro can hand off directly to one another while preserving their shared audio-path settings.\r\n\r\n> [!CAUTION]\r\n> Receive-only applications do not make protected frequencies suitable for experimentation.
