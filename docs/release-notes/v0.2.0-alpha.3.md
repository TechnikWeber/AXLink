> **Prerelease, not yet on the air.** The test plan: [BENCH.md](https://github.com/TechnikWeber/AXLink/blob/v0.2.0-alpha.3/docs/BENCH.md).

A security update since [v0.2.0-alpha.2](https://github.com/TechnikWeber/AXLink/releases/tag/v0.2.0-alpha.2); how AXLink works does not change.

- **`golang.org/x/net` 0.53.0 → 0.55.0**: fixes a denial of service in its HTML parser.
  `golang.org/x/sys` 0.43.0 → 0.45.0 comes along.
- Docs: serial port access is the group `dialout` on Fedora, Debian, Ubuntu and Raspberry Pi OS,
  `uucp` on Arch. Transmitting needs an amateur radio licence; AXLink comes as is, without warranty.

Packages as before: Linux (amd64, arm64, armv6), Windows (amd64, arm64, with `wintun.dll`),
macOS (arm64, amd64), `SHA256SUMS`. Start: [QUICKSTART.md](https://github.com/TechnikWeber/AXLink/blob/v0.2.0-alpha.3/docs/QUICKSTART.md).
The programs are not signed. Use your own callsign; every operator is responsible for what is
allowed on their frequency.
